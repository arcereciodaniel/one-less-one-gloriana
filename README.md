# one - one — Gloriana

Versión personalizada de **one - one** basada en el código de **one-less-one-lab** (v8.4.0). Incluye Inicio, Presupuesto, Movimientos y herramientas opcionales Deudas, Cobros y Metas.

## Conservación de datos

El almacenamiento de esta versión usa claves propias de Gloriana (\`gloriana_one_less_one_*_v2\`), independientes de los repositorios Lab y Daniel. Los datos antiguos de Finanzas de Gloriana v1.3.1 (\`gloriana_finanzas_local_v1\`) no se eliminan ni se sobreescriben. Si el navegador conserva información previa, aparece un botón para exportarla en JSON. **El esquema antiguo no se importa automáticamente:** revisar y migrar sus datos requiere un paso posterior de conversión validada.

Los registros están en el almacenamiento local del navegador, no en GitHub. Antes de borrar datos, utilizar el respaldo JSON.
